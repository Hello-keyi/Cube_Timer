## 2. 用项目代码理解（10 分钟）

### 路由（`src/router/index.js` + `src/App.vue`）
```js
const router = createRouter({
  history: createWebHistory(),                 // HTML5 history 模式，URL 没有 #
  routes: [
    { path: '/', name: 'timer', component: TimerView },
    { path: '/history', name: 'history', component: HistoryView },
  ],
})
```
```vue
<RouterLink class="tab" to="/">计时</RouterLink>   <!-- 生成 <a href>，不会整页刷新 -->
<RouterView />                                    <!-- 当前路由对应的组件渲染在这里 -->
```

### 接口层（`src/api/records.js`）
```js
export async function fetchRecords() {
  const res = await fetch(BASE_URL + '/record/list')
  const json = await res.json()
  if (json.code !== 0) throw new Error(json.msg || '读取失败')   // 业务失败判定
  return json.data
}
```
**套路**：fetch → json → 判断 `code` → 返回 `data` 或抛错。**页面永远不直接 fetch**，都走 api 层。

### 异步状态（`src/composables/useRecords.js`）
- `records / loading / error` 三个 `ref`；`load()` 里 `loading=true → try → catch 写 error → finally loading=false`
- 这是 Vue 里做异步请求的**标准三件套**：**数据 + 加载中 + 错误**

## 6. 常见坑

1. **参数类型**：`size`/`page` 从 `ref` 传给 api 前不用手动转，模板数字字符串会拼进 URL，但后端 `int` 能解析；自己算 `总页数` 时记得 `Math.ceil(total / size)`
2. **后端 HTTP 200 但 code=1**：只判 `res.ok` 会漏掉业务失败 → 必须判 `json.code`
3. **接口/页面层不要混**：HistoryView 不写 `fetch`，只调 api 函数
4. **watch 的时机**：`watch(page, loadPage)` 放在 `onMounted` 外面；`loadPage` 里记得先清 `errorMsg`
5. **不要在模板里调用会发请求的函数**（如 `v-if="loadPage()"` 会无限请求）
6. **分页越界**：后端 page=99 返回空数组 + total 正常；前端要能处理"空列表"（显示"本页没有数据"或自动跳回第一页）
