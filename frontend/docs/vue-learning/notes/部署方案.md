## 0. 整体结构（部署后）

```
浏览器 → http://localhost/  (Nginx :80)
            ├── /            → frontend/dist 静态文件（index.html + assets）
            └── /api/*       → 反向代理到 http://127.0.0.1:8081/*
                                  ↓
                           Spring Boot jar :8081
                                  ├── MySQL :3306
                                  └── Redis :6379（D13 缓存）
```

**关键点**：前端代码里请求的是相对路径 `/api/...`，所以生产环境**同源**（80 → Nginx → 8081），
不需要改前端代码，也不需要处理 CORS。

## 2. 安装并配置 Nginx（需要 sudo）

```bash
# ① 安装
sudo apt update && sudo apt install -y nginx

# ② 写配置
sudo tee /etc/nginx/sites-available/cube-timer > /dev/null <<'CONF'
server {
    listen 80;
    server_name localhost;

    # 前端构建产物目录（按实际路径改）
    root /home/yi/workplace/project/Cube_Timer/frontend/dist;
    index index.html;

    # SPA：刷新 /history 等前端路由不 404
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 接口反向代理：/api/record/list → http://127.0.0.1:8081/record/list
    location /api/ {
        proxy_pass http://127.0.0.1:8081/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
CONF

# ③ 启用 + 检查 + 启动
sudo ln -sf /etc/nginx/sites-available/cube-timer /etc/nginx/sites-enabled/cube-timer
sudo nginx -t              # 语法检查，看到 syntax is ok 才继续
sudo systemctl restart nginx 2>/dev/null || sudo nginx   # WSL 没有 systemd 时直接 sudo nginx
```

> 注意 `proxy_pass` 末尾的 **`/`**：`/api/` + `http://127.0.0.1:8081/` 会把 `/api` 前缀去掉，
> 和后端接口 `/record/...` 对上（等价于开发期 Vite 的 rewrite）。

## 5. 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| `403 Forbidden` / `500` | Nginx 用户读不了 `/home/yi/...`：把 dist 拷到 `/var/www/cube-timer` 或给目录执行权限（`chmod o+x /home/yi`） |
| 刷新 /history 404 | 少了 `try_files $uri $uri/ /index.html;` |
| `/api/...` 返回 404 | `proxy_pass` 末尾少了 `/`，或后端没起 |
| `/api/...` 500 | 后端起了但连不上 MySQL/Redis（看 jar 日志） |
| 页面白屏 / 资源 404 | `root` 指向的不是 dist 目录，或文件没构建 |
