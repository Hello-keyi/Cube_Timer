## 0. 为什么学这个

项目里：计时器 `TimerDisplay` 结束后要把"毫秒数"告诉父组件 `TimerView`，父组件才能 `add()` 存后端 —— 这是**子 → 父（emit）**。
列表 `RecordList` 要接收父组件传进来的成绩数组 —— 这是**父 → 子（props）**。
所有 Vue 项目都靠这两招。

## 2. 用项目代码理解（10 分钟）

### 父 → 子：props
`RecordList.vue`：
```js
defineProps({
  records: { type: Array, default: () => [] },
  showDate: { type: Boolean, default: false },
  emptyText: { type: String, default: '还没有成绩' },
})
```
`TimerView.vue` 里使用：
```vue
<RecordList :records="recentRecords" empty-text="还没有成绩，点上面的按钮开始计时" />
```
- `:records` 是 v-bind，传的是**变量**；`empty-text` 传的是字符串
- props 是**单向**的：子组件不该直接改 props（改会警告）；需要变就让父组件变
- 命名：父组件写 kebab-case（`empty-text`），子组件声明 camelCase（`emptyText`）

### 子 → 父：emit
`TimerDisplay.vue`：
```js
const emit = defineEmits(['finish'])
...
emit('finish', Math.round(total))   // 把毫秒数发出去
```
`TimerView.vue` 接收：
```vue
<TimerDisplay @finish="handleFinish" />
```
```js
async function handleFinish(timeMs) { await add(timeMs) }
```
- `defineEmits(['finish'])` 声明事件；`emit('finish', 数据)` 触发并把数据带出去
- 父组件 `@finish="处理函数"` 接收，函数的参数就是 emit 的第二个参数

### 生命周期
- `onMounted`：组件挂载到页面**之后**执行（例：`TimerView` 的 `onMounted(() => load())` 拉后端数据）
- `onBeforeUnmount`：组件卸载**之前**执行（例：`TimerDisplay` 里 `onBeforeUnmount(() => cancelAnimationFrame(rafId))` 停动画，防内存泄漏）
- 顺序：创建 → 挂载(onMounted) → 更新 → 卸载前(onBeforeUnmount) → 卸载
- 先掌握这两个最常用的即可

### 速查表

| 写法 | 方向 | 用途 | 项目例子 |
|---|---|---|---|
| `defineProps({...})` | 父→子 | 声明接收的数据 | `RecordList` 的 records |
| `:prop="变量"` | 父→子 | 传数据 | `<RecordList :records="recentRecords" />` |
| `defineEmits(['x'])` | 子→父 | 声明事件 | `TimerDisplay` 的 finish |
| `emit('x', 数据)` | 子→父 | 触发事件带数据 | `emit('finish', ms)` |
| `@x="fn"` | 父 | 接收子事件 | `<TimerDisplay @finish="handleFinish" />` |
| `onMounted` | — | 挂载后执行 | `TimerView` 拉数据 |
| `onBeforeUnmount` | — | 卸载前清理 | `TimerDisplay` 停动画 |
| `v-model` | 双向 | 表单值绑定（props+emit 语法糖） | 练习 B 输入框 |

## 4. 练习 B：动手（25 分钟）⭐ 新功能：手动补录成绩

目的：练 props + emit，同时给项目加一个真实小功能（用的是**现有** `POST /record`，不需要等后端新接口）。

新建 `src/components/ScoreInput.vue`：
1. 一个输入框，输入**秒数**（如 `12.34`），用 `v-model` 绑定一个 `ref`
2. 一个"添加"按钮：点击时 `emit('add', 毫秒整数)`（提示：`Math.round(Number(input) * 1000)`）
3. 校验：空 / 非数字 / ≤0 → **不 emit**，显示错误提示（子组件自己的提示就行）

在 `TimerView.vue`（父组件）里使用：
1. `import ScoreInput from '@/components/ScoreInput.vue'`
2. template 里加 `<ScoreInput @add="handleManualAdd" />`（放 TimerDisplay 上/下都行）
3. script 里加：
```js
async function handleManualAdd(timeMs) {
  try {
    await add(timeMs)
  } catch {
    // 错误已由 useRecords 写到全局
  }
}
```

**验收**：
- [ ] 输入 12.34 → 点添加 → 列表出现 12.340；后端启动时数据库也多一条
- [ ] 输入 `abc` / 空 / `-1` → 不提交，有提示
- [ ] F12 Console 无报错
- [ ] 能口头讲清：数据怎么从子组件 → 父组件 → 后端

## 5. 提示与坑

- `defineProps` / `defineEmits` 只能在 `<script setup>` 顶层使用
- emit 事件名用小写（`finish`/`add`），父组件写 `@finish` / `@add`
- 输入框的值是**字符串**，要 `Number()` 转换并判断 `Number.isNaN(...)`
- 子组件不要直接修改 props
- `v-model` 本质是 `:value` + `@input` 的语法糖，今天顺手用，F5 表单再细讲
