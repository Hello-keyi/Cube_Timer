## 2. 设计思路（先想清楚再写）

需求：
- **历史页**每条成绩后面有"删除"按钮
- 点击 → 弹确认 → 调 `DELETE /record/{id}` → 成功后刷新当前页（总数也变）
- **计时页**的"最近 5 次"**不要**删除按钮（同一个 RecordList 组件复用）

方案：
1. `api/records.js` 加 `deleteRecord(id)`
2. `RecordList.vue` 加两个可选东西：
   - prop `showDelete`（Boolean，默认 false）→ 只有历史页传 true
   - emit `delete`：点击按钮时 `emit('delete', item.id)` 通知父组件（子组件**不直接发请求**，保持"展示组件"职责）
3. `HistoryView.vue`：
   - `:show-delete="true" @delete="handleDelete"`
   - `handleDelete(id)`：confirm → `await deleteRecord(id)` → `await loadPage()`；失败写 `errorMsg`

## 4. 练习 B：动手实现（这次你自己写，我 review）

### B1. `src/api/records.js`
```js
export async function deleteRecord(id) { ... }
```
要求：
- `fetch(BASE_URL + '/record/' + id, { method: 'DELETE' })`
- 判 `json.code !== 0` → `throw new Error(json.msg || '删除失败')`
- 成功不需要 return 值

### B2. `src/components/RecordList.vue`
- props 增加 `showDelete: { type: Boolean, default: false }`
- `const emit = defineEmits(['delete'])`
- 每条记录里加按钮：`<button v-if="showDelete" @click="emit('delete', item.id)">删除</button>`
- 加一点 scoped 样式（红色小按钮即可）

### B3. `src/views/HistoryView.vue`
- 模板：`<RecordList ... :show-delete="true" @delete="handleDelete" />`
- script：
```js
import { deleteRecord } from '@/api/records'

async function handleDelete(id) {
  if (!window.confirm('确定删除这条成绩吗？')) return
  try {
    await deleteRecord(id)
    await loadPage()          // 重新拉当前页（total 也会更新）
  } catch (e) {
    errorMsg.value = '删除失败：' + e.message
  }
}
```
- 注意：删除后如果当前页空了，`loadPage` 里的兜底会把 page 拉回最后一页（F4 已写好）

## 6. 常见坑

1. **子组件发请求**：不要，删除动作放父组件（HistoryView），子组件只 emit——这样组件可复用、职责清晰
2. **忘了 confirm**：删数据不可逆，必须二次确认
3. **只改本地数组不刷新**：total 不会变、翻页边界会错；以服务端为准重新拉
4. **重复点击**：请求没回来前按钮还可点 → 可以加 `deleting` 状态禁用（可选进阶）
5. **删除不存在的 id**：后端返回 `code:1 "记录不存在"`，前端应显示错误，不要当成功
