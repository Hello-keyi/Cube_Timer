### F2 · 响应式基础 ✅ 已完成（2026-10-27 ~ 10-29）

> **验收（10/29）**：ReactiveDemo 已能运行（AI 最小修补 5 处：import 路径、average 算法、count 按钮、显示格式、v-for）；问答已批改（见 `notes/F2-响应式-讲解与批改.md`）；练习残留已从 TimerView 移除。

**目标**：理解"改数据页面自动变"，会用 `ref`、`computed`、`watch`。

**读**（15 分钟）：
- 响应式基础：https://cn.vuejs.org/guide/essentials/reactivity-fundamentals.html
- 计算属性：https://cn.vuejs.org/guide/essentials/computed.html
- 侦听器：https://cn.vuejs.org/guide/essentials/watchers.html

**用项目理解**（10 分钟）：
- `TimerDisplay.vue`：`const display = ref('0.000')`，script 里 `display.value = ...`，模板里 `{{ display }}` 自动解包
- `TimerView.vue`：`const recentRecords = computed(() => records.value.slice(0, 5))` —— 依赖变了才重算
- `useRecords.js`：模块级 `const records = ref([])` → 所有组件共享同一份
- 一句话区分：要"算出来的值"用 `computed`；值变了要"做事"（请求/打印/定时器）用 `watch`

**练习 A（问答题）**：
1. 为什么 `ref` 在 script 里要 `.value`，模板里不用？
2. `computed` 的"缓存"是什么意思？`records` 不变时读 100 次会算 100 次吗？
3. 举一个项目里必须用 `watch` 而不是 `computed` 的场景。
4. `reactive({count:0})` 解构后改 `count`，页面还会更新吗？为什么？

**练习 B（动手）**：新建 `src/components/ReactiveDemo.vue`
1. `count = ref(0)` + 三个按钮：+1 / -1 / 归零
2. `scores = ref([61234, 12345, 78210])`
3. 三个 `computed`：`total`（次数）、`avg`（平均，用 `formatMs` 显示秒 3 位）、`best`（最小值）
4. 按钮"加一条随机成绩"：`scores.value.push(5000~90000 随机整数)`
5. `watch(count, (n, o) => ...)` 把"上次点击：o → n"显示到页面（提示文字用 `ref` 存）

## 10. 易错清单（前端，随时补充）

**SFC / 组合式 API**
- `<script>` 写成了 `<script setup>` 才能自动把变量暴露给模板（否则模板全 undefined）
- `defineProps` 是接父组件数据；`defineExpose` 是暴露给父组件，别混
- 模板里用到的函数/变量必须在 `<script setup>` 里 import 或定义，否则运行时整组件不渲染
- 响应式数据在 script 里要 `.value`，模板里自动解包（模板自动解包是编译器帮忙）；模板事件里可直接写 `count++`，Vue 内部用 proxyRefs 代理 setupState，读写都会落到 `.value`
- `computed` 用于派生值（有缓存、无副作用）；`watch` 用于"值变了做动作"（请求/存储/日志），且必须先 `import { watch }`
- `reactive` 对象解构会丢响应性（用 `toRefs` 或直接 `state.xxx`）；但 composable 返回的 ref 解构不丢响应

**排查**
- 页面没反应 → 先 F12 Console（第一个现场）→ 再看终端编译报错 → 最后看逻辑
- `npm run build` 通过 ≠ 运行正确（运行时错误只有浏览器/Console 能看到）
- 接口失败先 `curl http://localhost:8081/record/list` 确认后端

**布局/样式**
- `position: fixed;` 会让元素脱离文档流、盖住别的内容；不加 top/left 不可控
- `<style scoped>` 会给元素加 `data-v-xxx`，不代表 class 没对上

**接口/代理**
- 前端请求必须带 `/api` 前缀（代理才会去掉）；直接写 `/record` 会打到 5173
- 后端改契约没通知前端 → 页面报错/白屏；看后端文档 4.2 + 本文 4.2

## 13. 前端术语表（后端视角对照）

| 术语 | 含义 |
|---|---|
| SFC | 单文件组件（`.vue` = `<script setup>` + `<template>` + `<style>`） |
| 响应式 | 数据变了页面自动更新（`ref`/`reactive`） |
| `computed` | 有缓存的派生值，依赖变化才重算 |
| `watch` | 监听值变化后执行副作用 |
| props | 父组件传给子组件的数据（只读） |
| emit | 子组件通知父组件的事件 |
| 生命周期 | `onMounted`（挂载后）、`onBeforeUnmount`（卸载前）等 |
| composable | 可复用的组合式函数（如 `useRecords`） |
| 路由 | URL 与页面组件的映射（`vue-router`） |
| 代理 | 开发期 Vite 把 `/api` 转给后端，避免跨域 |
| 契约 | 前后端约定的接口形状（路径/参数/返回结构） |
