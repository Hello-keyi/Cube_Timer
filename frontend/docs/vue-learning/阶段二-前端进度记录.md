**预答题批改**
- Q1（为什么要 `/record/full`）：答"方便数据处理，原子性？" → 🟡 原子性是核心 ✅；补充：一次请求还减少网络往返/避免前端中间态

**后端契约（已核实）**
- `POST /user/register` body `{username(3-20), password(6-32), nickname?}` → `Result<Void>`；错误：用户名已存在 / 校验失败
- `POST /user/login` body `{username, password}` → `Result<{id, username, nickname, token}>`；错误：用户名或密码错误 / 该用户被禁用
- 其余 `/record/**` 需请求头 `Authorization: Bearer <token>`；缺失/过期返回 **HTTP 401** + `{code:1,msg:"未登录，请先登录"/"登录已过期..."}`
- token 有效期 2 小时（`ttl: 7200000`）
- `POST /record/full` body `{timeMs(1..600000), scrambles?: string[]}` → `Result<Void>`（F8 用）

**已植入的骨架（编译通过）**
