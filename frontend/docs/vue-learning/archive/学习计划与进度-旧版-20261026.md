# Vue 3 学习计划与进度（魔方计时器项目实战版）

> 学习方式：边做项目边学，**只学组合式 API（`<script setup>`）**
> 环境：VS Code + Vue - Official (Volar)；后端用 IDEA（Java 继续用）

## 一、目标（学完能做到）

- [ ] 看懂并改得动 `frontend/src` 里每一个文件
- [ ] 独立给魔方计时器加新页面 / 新功能
- [ ] 讲清数据流：API → composable → 组件 → DOM
- [ ] Vue 基础面试题能答（v-if/v-show、ref/reactive、computed/watch、组件通信、生命周期、路由）

## 二、学习规则（每天）

1. 看 15 分钟官方文档（Vue 中文文档「基础」章节）→ 动手 40 分钟 → 3 行笔记
2. 代码**自己写**，AI 只 review / 出题 / 讲错因，不代写
3. 卡住超过 10 分钟再提问
4. 每天把进度填到下面的「进度打卡」
5. 每阶段末做一次验收，不通过不进下一阶段
6. 学习期先关闭 Copilot 自动补全；用了 Copilot 的代码必须能逐行解释，否则删掉重写

## 六、待复习 / 易错清单（随时补充）

- defineProps 和 defineExpose 的区别（D1 踩坑）
- 模板里用到的函数/变量必须在 `<script setup>` 里定义或 import，否则运行时整个组件不渲染
- v-if vs v-show（已能答对，保持）
- v-for 的 :key 作用：不写不报错，但按索引复用 DOM，重排/删除会出问题
- position: fixed / absolute / relative / static 的区别与文档流（D1 布局坑）
- 用 Copilot 的规矩：学习期关自动补全；用了要能逐行解释
- 浏览器 F12 Console 是排查"页面没反应"的第一现场
